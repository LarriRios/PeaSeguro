# PeaSeguro 🚶‍♂️
PeaSeguro es un prototipo de aplicación orientada a la seguridad peatonal en la ciudad de Popayán. El proyecto fue desarrollado como parte de una actividad académica enfocada en el diseño y prototipado de soluciones tecnológicas para la movilidad y la seguridad vial.

Contenido del repositorio

Este repositorio contiene el archivo generado durante el proceso de desarrollo del prototipo utilizando Claude.

Archivo principal
PeaSeguro.html

Este archivo corresponde al prototipo interactivo desarrollado en HTML y permite visualizar la estructura, navegación y funcionalidades propuestas para la aplicación. El prototipo incluye interfaces para peatones, conductores y entidades de tránsito, así como módulos relacionados con reportes, estadísticas y educación vial.
